問題與解法

為什麼要做這個？

😩 現有的痛點
  • ✗ 出國前要查天氣，要開瀏覽器搜尋等載入
  • ✗ 查匯率要開另一個網站，再換算金額
  • ✗ 每次都要重複同樣的操作，很浪費時間
✅ 我們的解法
  • ✓ 在終端機輸入城市名稱，即時顯示天氣
  • ✓ 輸入兩個貨幣代碼，秒顯示匯率與換算
  • ✓ 一個工具解決兩個需求，快速又方便
🎯 目標使用者
✈️ 出國旅遊者 💼 商務人士 👩‍💻 開發者／學生

📁 程式結構
main.py ← 主程式，互動 & 命令列雙模式
weather.py ← 城市地理編碼 → 天氣查詢 → 格式化輸出
exchange.py ← 貨幣驗證 → 匯率查詢 → 換算輸出
requirements.txt ← 只需要 requests 一個套件
